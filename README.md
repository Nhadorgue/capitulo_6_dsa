# 📊 Estudos em Python — Data Science Academy (DSA)

Este repositório reúne **exercícios, capítulos práticos e mini-projetos desenvolvidos em Python**, com foco no aprendizado progressivo de **programação, análise de dados e fundamentos de ciência de dados**, seguindo a metodologia da **Data Science Academy (DSA)**.

O objetivo principal é **consolidar conceitos teóricos por meio da prática**, utilizando notebooks Jupyter para facilitar a visualização, testes e evolução do código ao longo do aprendizado 🧠💻

---

## 📂 Estrutura do Repositório

O repositório está organizado em **notebooks Jupyter (`.ipynb`)**, cada um com um propósito específico:

- 📘 **Capítulos**  
  Notebooks focados na explicação e prática de conceitos fundamentais da linguagem Python, como:
  - Tipos de dados
  - Estruturas condicionais
  - Laços de repetição
  - Funções
  - Manipulação de dados

- 📝 **Listas de Exercícios**  
  Exercícios práticos para fixação do conteúdo, estimulando:
  - Raciocínio lógico
  - Resolução de problemas
  - Escrita de código limpo e organizado

- 🚀 **Mini Projetos**  
  Aplicações práticas que simulam problemas reais, integrando múltiplos conceitos aprendidos ao longo dos estudos.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 🐍  
- **Ambiente:** Jupyter Notebook  
- **Principais Bibliotecas:**
  - `numpy`
  - `pandas`
  - Bibliotecas nativas do Python
